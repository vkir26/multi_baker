# Service Multibakers (Сервис мультипекарей)

**Service Multibakers** — помогает решить проблему выбора подходящей модели мультипекаря, в зависимости от предпочтений пользователя.

Идея в том чтобы пользователь выбрал модель мультипекаря которая подходит именно ему, по изначально заложенным производителем панелям в комплекте.

Здесь собрана общая база моделей мультипекарей, благодаря чему не требуется искать информацию по моделям на разных ресурсах, всё собрано в одном месте.

# Функциональность

- Добавление новых моделей с панелями
- Отдельный выбор интересующей модели или панели по ID
- Показать общий список моделей или панелей разделенных нумерацией страниц (пагинация)

# Установка и запуск

Требования: `Python ≥3.13`, `uv`. Для веб-запуска — `Docker`.

Локальные зависимости: `uv sync`

Способы запуска:

- веб (основной) — `Docker Compose`, `HTTP API` за `nginx`
- CLI — локально через `uv`, для проверки и работы с данными

# Использование

**Основной веб-запуск:**

`docker compose up --build`

- Сервис доступен на `http://localhost` (nginx, порт 80).
- Миграции Alembic контейнер применяет сам при старте.

*Остановка*: `docker compose down`

**Alembic (локально, если работаешь через CLI):**

`uv run alembic upgrade head`

- Создаёт SQLite БД в `files/` и применяет таблицы.

**CLI (локально):**

```bash
uv run python main.py --help                                                        # показать список доступных команд.
uv run python main.py file-parse --file='путь/к/файлу.csv'                                      # парсинг файла CSV и запись данных в БД
uv run python main.py get-model --by_id='ID модели'                                   # поиск модели по ID.
uv run python main.py get-models --page='номер страницы'                            # показать список моделей на странице.
uv run python main.py get-panel --by_id='ID панели'                                   # поиск панели по ID.
uv run python main.py get-panels --page='номер страницы'                            # показать список панелей на странице.
uv run python main.py add-model --model='название модели' --panel='название панели' # добавить новую модель мультипекаря с панелями.
# Несколько панелей: повтори --panel (--panel A --panel B).
```

- Перед командами нужен `uv run alembic upgrade head`.

**HTTP API (локально, без Docker):**

`uv run uvicorn web_baker:app --app-dir app --reload`

- Сервис: `http://localhost:8000`. Перед стартом — `uv run alembic upgrade head`.
- Примеры запросов: [смотреть раздел API](#API)

# Архитектура

```
main.py — команды из терминала (Click)
app/ — веб-сервис HTTP API (FastAPI) и работа с базой данных
files/ — файл базы SQLite
migrations/ — создание и обновление таблиц
Dockerfile, compose.yaml, nginx.conf — запуск в Docker
static/ — файлы для сайта (картинки и т.п.), отдаёт nginx
```

# API


| Метод  | Endpoint        | Описание                   |
| ------ | --------------- | -------------------------- |
| `GET`  | `/`             | Приветствие (JSON)         |
| `POST` | `/v1/model/add` | Добавить модель            |
| `GET`  | `/v1/model`     | Модель по ID (`by_id`)     |
| `GET`  | `/v1/models`    | Список моделей (пагинация) |
| `GET`  | `/v1/panel`     | Панель по ID (`by_id`)     |
| `GET`  | `/v1/panels`    | Список панелей (пагинация) |
