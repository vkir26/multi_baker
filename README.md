# Service Multibakers (Сервис мультипекарей)

**Service Multibakers** — помогает решить проблему выбора подходящей модели мультипекаря, в зависимости от предпочтений пользователя.

Идея в том чтобы пользователь выбрал модель мультипекаря которая подходит именно ему, по изначально заложенным производителем панелям в комплекте.

Здесь собрана общая база моделей мультипекарей, благодаря чему не требуется искать информацию по моделям на разных ресурсах, всё собрано в одном месте.

# Функциональность
- Добавление новых моделей с панелями
- Отдельный выбор интересующей модели или панели по ID
- Показать общий список моделей или панелей разделенных нумерацией страниц (пагинация)

# Установка и запуск
Требования: `Python`

Установка зависимостей из `pyproject.toml` зависит от используемого менеджера пакетов:

**Использование "Poetry"**
 ```
 poetry install
```
**Использование "pip"**
 ```
 pip install .
```
**Использование "uv"**
 ```
 uv sync
 uv pip install
```

Проект поддерживает два способа запуска:
- через `CLI` для локального использования
- через `HTTP API` на базе `FastAPI`

# Использование
**Alembic:**
```python
alembic upgrade head # применяет миграции к базе данных (при необходимости создаёт БД и все таблицы).
```
**CLI (Интерфейс командной строки):**
```python
run main.py --help                                                        # показать список доступных команд.
run main.py 'COMMANDS' --help                                             # показать список настроек для команды.
run main.py file-parse --file='файл'                                      # парсинг файла CSV и запись данных в БД
run main.py get-model by_id='ID модели'                                   # поиск модели по ID.
run main.py get-models --page='номер страницы'                            # показать список моделей на странице.
run main.py get-panel by_id='ID модели'                                   # поиск панели по ID.
run main.py get-panels --page='номер страницы'                            # показать список панелей на странице.
run main.py add-model --model='название модели' --panel='название панели' # добавить новую модель мультипекаря с панелями.
# несколько панелей: добавить настройку --panel=`'название панели' через пробел повторно.
```
**FastAPI:**
```python
fastapi dev main.py # запуск веб-сервера в режиме *разработчика*
fastapi run main.py # запуск веб-сервера в режиме *продакшен*
```
- примеры запросов: [смотреть раздел API](#API)

# API

| Метод      | Endpoint          | Описание                 |
| ---------- | ----------------- | ------------------------ |
| `GET`      | `/`               | Главная страница         |
| `GET/POST` | `/v1/model/add`   | Добавить модель          |
| `GET`      | `/v1/model`       | Получить модель по ID    |
| `GET`      | `/v1/models`      | Страница с моделями      |
| `GET`      | `/v1/panel`       | Получить панель по ID    |
| `GET`      | `/v1/panels`      | Страница с панелями      |
